## 1. `backend/Models/user.py`

### Source Code & Walkthrough

```python
14: def generate_customer_id():
15:     return f"CUST-{random.randint(100000, 999999)}"
```
* **What it does:** Generates a random 6-digit customer identifier string prefixed with `CUST-` (e.g. `CUST-482910`).
* **Why it exists:** Provides human-readable user tracking IDs alongside internal UUID primary keys.

* **Line 16: `id`**: Primary key GUID generated with `uuid.uuid4()`.
* **Lines 21-22: `latitude`/`longitude`**: Floating point GPS coordinates used by Haversine distance queries in `Services/geo_service.py`.
* **Lines 33-35: `performers`, `highlights`, `ticket_types`**: Text columns storing JSON-serialized string structures for complex event metadata.
* **Line 40: `customer_id`**: Foreign key linking event ownership directly to `users.customer_id` with cascading update/delete behavior.
